# Metabolic Reset: Launch Ad Pack v1 (L1–L4)

Built 20 Oct 2026 for the go-live on Thu 3 Dec. Objective: **Sales**. CTA button: **Shop now**. Copy CTA: "shop now".
Every ad is built twice in Canva: **4:5** 1080×1350 (feed) and **9:16** 1080×1920 (Stories/Reels). Text-only templates; drop in the named shot.

Footer for every ad's primary text:
> Always read the label and follow the directions for use. If symptoms persist, see your healthcare professional. Dietary supplements are not a replacement for a balanced diet.

**[CONFIRM]** = run only once the fact is true. **[REVIEW]** = use a real, verified customer review only; never write one. Pre-launch rules still apply: structure/function claims only, no em dashes.

## Why build these now, before the hook test reads out

The plan was to wait for C1 winners (~22 Nov). These are built now so launch isn't blocked on design, but L1 is deliberately spread across the C1 hook families (3pm gap, three systems, read the label, fashion). On 22 Nov, keep the L1 ads whose hook won in C1 and switch the rest off. Don't run all 8 at once.
